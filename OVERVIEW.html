🔧 Hızlı Komutlar

Derle: cd hiroki-os && sudo ./build.sh → out/hiroki-os-1.0-x86_64.iso

Doğrula: sha256sum -c out/*.sha256

QEMU Live: qemu-system-x86_64 -enable-kvm -m 2048 -cdrom out/*.iso -boot d

Düşük RAM testi: qemu-system-x86_64 -m 512 -cdrom out/*.iso → i3 öneri & uyarı

Donanım algıla: hiroki-hw-detect && cat /tmp/hiroki-hw-info.json

DE Seçici: hiroki-de-selector   Welcome: hiroki-welcome --force

Tema: hiroki-theme-manager   Güncelle: hiroki-update   Sürücü: hiroki-driver-manager
